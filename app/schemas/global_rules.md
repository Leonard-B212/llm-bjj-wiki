# Global Note Writing Rules

- Do NOT include the title as a heading.
- The title will be used as the filename.
- Technique names and links should use standard English BJJ names.
- Descriptive content should be written in {LANGUAGE}.
- Filename should be the core technique name only.
- Do NOT add source positions to the filename.
- Do not include unnecessary explanations outside the note content itself.
- Example: use `Straight-Ankle-Lock.md`, not `Straight-Ankle-Lock-from-Ashi-Garami.md`.
- Example: use `Armbar.md` or `Armbar-Variant.md`, not `Armbar-from-Mount.md`, unless the variation is fundamentally different.
- Always include every heading and subheading defined in the schema, even if no information was provided for it. In that case, write a single placeholder bullet: `* TBD`.
- Do not skip, merge, or omit schema sections for any reason.
- Link any referenced BJJ position, technique, or transition using [[Name]], even in flowing text within a section (e.g. "attacking from [[Side-Control]]").
- All technique and position names (in filenames, links, and headings) must use Hyphen-Case: every word starts with a capital letter, words are separated by hyphens, no spaces. Example: `Side-Control`, `Knee-Elbow-Escape`, `Bow-and-Arrow-Choke`.
- Existing note titles are canonical wiki entities. If a referenced concept matches an existing note, ALWAYS use its exact title as the link target.
- Top/bottom and offensive/defensive describe perspective, not separate position entities. Example: "top side control" and "bottom side control" must both link to `[[Side-Control]]` if `Side-Control` exists.
- Links to non-existing notes are allowed only when they represent a genuinely different BJJ concept.

- Keep established Brazilian Jiu-Jitsu terminology in English, even when descriptive content is written in another language.
- Do not translate common BJJ terms such as Underhook, Overhook, Crossface, Bridge, Shrimp, Guard, Mount, Side Control, Scramble, Frame, Base, Grip, Hook, Post, or Reversal into the content language.
- Use the commonly established BJJ term instead of literal translations (e.g. "Underhook", never "Unterhaken").

- Only create wiki links for positions, techniques, submissions, escapes, sweeps, passes, takedowns, throws, and meaningful transitions.
- Do NOT create wiki links for generic BJJ mechanics, grips, controls, body parts, or movement concepts such as S-Grip, Underhook, Overhook, Crossface, Frame, Base, Shrimp, Bridge, Grip, Hook, or Post, unless an existing canonical note with that exact title already exists.
