# Global Note Writing Rules

- Do NOT include the title as a heading.
- The title will be used as the filename.
- Technique names and links should use standard English BJJ names.
- Descriptive content should be written in {LANGUAGE}.
- Filename should be the core technique name only.
- Do NOT add source positions to the filename.
- Do not include unnecessary explanations outside the note content itself.
- Example: use `Straight-Ankle-Lock.md`, not `Straight-Ankle-Lock-from-Ashi-Garami.md`.
- Example: use `Armbar.md` or `Armbar-Variant.md`, not `Armbar-from-Mount.md`, unless the variation is fundamentally different.
- Always include every heading and subheading defined in the schema, even if no information was provided for it. In that case, write a single placeholder bullet: `* TBD`.
- Do not skip, merge, or omit schema sections for any reason.
- Link any referenced BJJ position, technique, or transition using [[Name]], even in flowing text within a section (e.g. "attacking from [[Side-Control]]").
- All technique and position names (in filenames, links, and headings) must use Hyphen-Case: every word starts with a capital letter, words are separated by hyphens, no spaces. Example: `Side-Control`, `Knee-Elbow-Escape`, `Bow-and-Arrow-Choke`.
