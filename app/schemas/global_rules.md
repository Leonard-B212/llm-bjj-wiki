# Global Note Writing Ruls

- Do NOT include the title as a heading.
- The title will be used as the filename.
- Return ONLY raw JSON.
- Do not use markdown code fences.
- Do not wrap JSON in ```json.
- Technique names and links should use standard English BJJ names.
- Descriptive content should be written in German.
- Filename should be the core technique name only.
- Do NOT add source positions to the filename.
* Do not include explanations
- Example: use `Straight-Ankle-Lock.md`, not `Straight-Ankle-Lock-from-Ashi-Garami.md`.
- Example: use `Armbar.md` or `Armbar-Variant.md`, not `Armbar-from-Mount.md`, unless the variation is fundamentally different.
